`main.py` (Python 3.13, standard library only) writes one plan to
`/output/entry.txt`: build a single $39 abandoned-cart email pack for
Shopify stores on day 1, then spend days 2–30 finding 200 stores via
BuiltWith, pitching owners through their contact forms, and selling the
pack on Gumroad — 12 sales = $468. One asset, reused; no stock, no ads,
no luck. Every step is work an AI agent can do itself with a browser,
code, APIs and $100.
